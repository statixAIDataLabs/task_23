1 Start Here

2 1. Introduction to data.table

data.table is an R package for selecting, changing, grouping, and joining tables. It extends data.frame and provides concise operations that can avoid unnecessary copies. A data.frame is R’s standard rectangular data structure. A data.table is also rectangular, but its := operator can update columns by reference, and its joins and grouped calculations are designed for efficient work.

The common syntax is DT[i, j, by]: i chooses rows, j chooses or calculates columns, and by defines groups. data.table() creates a data.table from named vectors. head() displays its first rows. str() describes column names and data types. dim() returns row and column counts.

small_dt <- data.table(
  USUBJID = c("SUBJ-001", "SUBJ-002", "SUBJ-003"),
  AGE = c(34, 67, 52),
  TRT01A = c("Drug A", "Placebo", "Drug A")
)

3 2. Column operations and reducing copies

The := operator adds or modifies columns by reference. This updates the existing table instead of creating a full modified copy. fifelse() is data.table’s fast, type-consistent conditional function. The age bands below are examples only, not a clinical standard. copy() makes a separate data.table when the original must stay unchanged.

age_example <- copy(adsl)
age_example[, AGEGR1 := fifelse(AGE < 40, "<40", "40+")]
age_example[, AGE_NEXT_YEAR := AGE + 1]
head(age_example[, .(USUBJID, AGE, AGEGR1, AGE_NEXT_YEAR)])
    USUBJID   AGE AGEGR1 AGE_NEXT_YEAR
     <char> <int> <char>         <num>
1: SUBJ-001    65    40+            66
2: SUBJ-002    70    40+            71
3: SUBJ-003    24    <40            25
4: SUBJ-004    81    40+            82
5: SUBJ-005    36    <40            37
6: SUBJ-006    53    40+            54

Line by line: copy ADSL so the source remains unchanged; add AGEGR1 using the stated age condition; add a numeric next-year age; then display only the four named columns. .() is a short way to make the selected list of output columns.

Ordinary base-R data.frame assignment follows copy-on-modify: changing the copy normally leaves the original alone. A second name for a data.table refers to the same table, so a := update can be seen through either name. Use copy() before a reference update when you need to preserve the starting data.

base_original <- as.data.frame(adsl)
base_changed <- base_original
base_changed$AGE[1] <- base_changed$AGE[1] + 1
c(original = base_original$AGE[1], changed = base_changed$AGE[1])

      65       66

dt_alias <- dt_original

          changed alias_sees_change 
               66                66 
safe_copy <- copy(adsl)

Use copy() before modifying an input needed later or when creating a fair comparison. Avoid copying when an in-place update is safe. See the column lesson.

4 3. Efficient filtering

Filtering selects rows that meet conditions. In base R, the row condition goes before the comma and selected columns follow it. In data.table syntax the condition is also before the comma, and selected columns can be named inside .().

all.equal() compares results; isTRUE() gives a simple TRUE/FALSE answer; stopifnot() stops if the comparison fails. This makes the equivalence check executable rather than an assumption.

adults_base <- as.data.frame(adsl)
adults_base <- adults_base[adults_base$AGE >= 65,
                           c("USUBJID", "AGE", "TRT01A")]
adults_dt <- adsl[AGE >= 65, .(USUBJID, AGE, TRT01A)]
stopifnot(isTRUE(all.equal(
  adults_base, as.data.frame(adults_dt), check.attributes = FALSE
)))

5 4. Grouping and summarization

Grouping calculates a separate result for each category. by names the grouping variables. .N counts rows in the current group, while uniqueN() counts distinct values. Thus .N in ADLB counts lab rows, not people. .() creates named output columns. Since each ADSL row is one subject, uniqueN(USUBJID) explicitly counts subjects.

subject_counts <- adsl[
  , .(N_RECORDS = .N, N_SUBJECTS = uniqueN(USUBJID)), by = TRT01A
]
subject_counts[order(TRT01A)]
    TRT01A N_RECORDS N_SUBJECTS
    <char>     <int>      <int>
1:  Drug A        35         35
2:  Drug B        12         12
3: Placebo        33         33

order() returns row positions in sorted order. mean(), median(), min(), and max() calculate numeric summaries. na.rm = TRUE skips missing values; sum(!is.na(AVAL)) counts valid results. The following code summarizes each laboratory parameter.

6 5. Joins using data.table

A join matches rows between two tables using shared identifier columns. ADSL has subject-level information; ADLB has repeated lab records. Joining adds age, sex, and treatment to each matched lab row. ADSL has one row per subject, while each subject has multiple ADLB rows. Repeated subject values in a join result are expected.

Base R merge() combines matching rows; all = FALSE requests only matches. A data.table join has the form X[i, on = "key"]: it looks up each row of i in X. Thus adsl[adlb, on = "USUBJID"] starts from the lab records and adds matched subject columns.

base_join <- merge(as.data.frame(adsl), as.data.frame(adlb),
                   by = "USUBJID", all = FALSE)
join_by_on <- adsl[adlb, on = "USUBJID"]
head(join_by_on)

setkey() sorts a data.table by its key and records that ordering for lookups and joins. It changes the table by reference, so use copy() if the original order matters. on names join columns explicitly and is clear for a one-off join. A key can help with repeated lookups on the same column, but building one has a cost.

adsl_keyed <- copy(adsl)
setkey(adsl_keyed, USUBJID)
keyed_join <- adsl_keyed[adlb, on = "USUBJID"]
base_check <- as.data.table(base_join)
dt_check <- copy(keyed_join)
setorder(base_check, USUBJID, PARAMCD)
setorder(dt_check, USUBJID, PARAMCD)
stopifnot(isTRUE(all.equal(
  as.data.frame(base_check), as.data.frame(dt_check), check.attributes = FALSE
)))
cat("Validated matched records:", nrow(dt_check), "\n")
Validated matched records: 320

setorder() sorts rows in place. The code sorts both outputs to a common order before comparing; it checks values, not just row counts. Join order and column order can differ between methods, so check both when downstream code depends on them.

A left join keeps every row from its left table. In merge(), all.x = TRUE preserves unmatched rows in x and fills missing columns with NA. Duplicate keys can create several output rows for one input row. rbind() stacks rows from tables with the same columns. This small example adds a lab record with no subject match to show the behavior.

left_join <- merge(as.data.frame(adsl), as.data.frame(adlb),
                   by = "USUBJID", all.x = TRUE)
lab_with_unmatched_id <- rbind(
  as.data.frame(adlb),
  data.frame(USUBJID = "SUBJ-NOT-IN-ADSL", PARAMCD = "ALT", AVAL = 22)
)
matched_only <- merge(as.data.frame(adsl), lab_with_unmatched_id,
                      by = "USUBJID", all = FALSE)
all_lab_rows <- merge(as.data.frame(adsl), lab_with_unmatched_id,
                      by = "USUBJID", all.y = TRUE)
c(left_join_rows = nrow(left_join), matched_rows = nrow(matched_only),
  all_lab_rows = nrow(all_lab_rows))
left_join_rows   matched_rows   all_lab_rows 
           320            320            321

The unmatched lab row is excluded by the inner join and retained by all.y = TRUE. merge() can sort rows and its output column order should be checked. See the join lesson.

8 7. Performance comparison

8.1 Verify before timing

bench::mark() runs expressions repeatedly and measures time and memory. First compare equivalent results; only then time the same input data. as.data.frame() converts a table to base-R data.frame form, while as.data.table() converts it back. rep() repeats a sequence, seq_len() creates a sequence of row numbers, and match() finds each lab record’s subject position. sprintf() formats unique synthetic subject IDs. The following code uses them to expand the seeded inputs to 80,000 subjects and 320,000 lab records. This remains simulated data. aggregate() is a base-R grouped summary function. The data.table subject key is prepared before timing, so the join measurement excludes the one-time key setup cost.

subject_repeats <- 1000L
source_subject <- rep(seq_len(nrow(adsl)), times = subject_repeats)
bench_adsl <- as.data.frame(adsl[source_subject])
bench_adsl$USUBJID <- sprintf("BENCH-%06d", seq_len(nrow(bench_adsl)))
lab_source <- rep(seq_len(nrow(adlb)), times = subject_repeats)
lab_repeat <- rep(seq_len(subject_repeats), each = nrow(adlb))
source_subject_index <- match(adlb$USUBJID, adsl$USUBJID)
bench_adlb <- as.data.frame(adlb[lab_source])
bench_adlb$USUBJID <- sprintf(
  "BENCH-%06d",
  (lab_repeat - 1L) * nrow(adsl) + source_subject_index[lab_source]
)
bench_adlb$TRT01A <- bench_adsl$TRT01A[
  match(bench_adlb$USUBJID, bench_adsl$USUBJID)
]
bench_adlb_join <- bench_adlb[, c("USUBJID", "PARAMCD", "AVAL")]
bench_adsl_dt <- as.data.table(copy(bench_adsl))
bench_adlb_dt <- as.data.table(copy(bench_adlb))
bench_adlb_join_dt <- as.data.table(copy(bench_adlb_join))
setkey(bench_adsl_dt, USUBJID)

8.2 Measure and read results

Each bench::mark() call uses the same inputs for both methods. iterations = 5 requests five runs, and check = FALSE is acceptable here because explicit checks were just run. The median is the middle measured elapsed time. mem_alloc is memory allocated by one expression, not all memory held by R. itr/sec estimates iterations per second. gc/sec reports garbage-collection activity per second; a missing value means none was observed. Measurements vary by computer, R version, package version, and background work.

filter_bench <- bench::mark(
  base_r = bench_adsl[bench_adsl$AGE >= 65,
                      c("USUBJID", "AGE", "TRT01A")],
  data_table = bench_adsl_dt[AGE >= 65, .(USUBJID, AGE, TRT01A)],
  iterations = 5, check = FALSE
)
group_bench <- bench::mark(
  base_r = aggregate(AVAL ~ TRT01A + PARAMCD, data = bench_adlb,
                     FUN = mean, na.rm = TRUE),
  data_table = bench_adlb_dt[
    , .(AVAL = mean(AVAL, na.rm = TRUE)), by = .(TRT01A, PARAMCD)
  ],
  iterations = 5, check = FALSE
)
join_bench <- bench::mark(
  base_r = merge(bench_adsl, bench_adlb_join,
                 by = "USUBJID", sort = FALSE),
  data_table = bench_adsl_dt[bench_adlb_join_dt, on = "USUBJID"],
  iterations = 5, check = FALSE
)

as.numeric() converts bench’s displayed time and memory values to seconds and bytes. write.csv() stores simple columns only. These are measurements from this render; do not copy fixed values into the source document or claim an improvement that the results do not show.

benchmark_rows <- function(result, task_name) {
  data.frame(
    task = task_name,
    implementation = c("base R", "data.table"),
    median_seconds = as.numeric(result$median),
    memory_bytes = as.numeric(result$mem_alloc),
    iterations_per_second = as.numeric(result$`itr/sec`),
    gc_per_second = as.numeric(result$`gc/sec`)

9.2 Common beginner errors

  • Use DT[condition, .(columns)] for clear data.table filtering.
  • Remember := updates by reference; use copy() when the original must remain unchanged.
  • .N counts rows, not unique subjects; use uniqueN(USUBJID) for subjects.
  • mean() returns NA if values are missing unless na.rm = TRUE; use that option only when appropriate.
  • Repeated join keys can multiply rows. Check key uniqueness and expected join row counts.
  • Sort and align columns before output comparisons; do not assume joins match without validation.
  • setkey() sorts and modifies a table. Include its cost if the workflow rebuilds the key every time.
  • Benchmark results vary by machine. Report only values measured in this run.
